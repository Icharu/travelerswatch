# دليل البدء السريع

ثبّت The Traveler's Watch (‏TTW)، وحدّد مسار مشروعك في اليوم الأول، ثم استخدمها كل يوم بعد ذلك. العودة إلى [README](README.md).

**TTW تُقاد يومًا بيوم (daily-led).** أنت من يقود عمل كل يوم. يُبقي الحارس المسار أمام الأعين مع كل طلب، ويحفظ السجل التاريخ؛ فيبدأ كل يوم من حيث يقف المشروع فعلًا، لا مما يتذكره النموذج.

## 1. التثبيت

اختر طريقة واحدة.

| الطريقة | ما تحصل عليه |
|---|---|
| **إضافة Claude Code** (موصى بها) | المهارات + الحارس التلقائي. الأوامر: `/travelerswatch:checkwatch` و`/travelerswatch:fixwatch` و`/travelerswatch:configwatch` |
| **المهارات فقط** (Claude Code أو أي وكيل يقرأ [Agent Skills](https://agentskills.io/)) | المهارات دون الحارس. الأوامر: `/checkwatch` و`/fixwatch` و`/configwatch`. شغّل `/checkwatch` يدويًا في بداية كل جلسة. |
| **التجربة دون تثبيت** | كل شيء، لهذه الجلسة فقط |

</div>

```text
# Claude Code plugin
/plugin marketplace add Icharu/travelerswatch
/plugin install travelerswatch@travelerswatch
```

```bash
# Skills only
git clone https://github.com/Icharu/travelerswatch
cp -r travelerswatch/skills/checkwatch travelerswatch/skills/fixwatch travelerswatch/skills/configwatch ~/.claude/skills/

# Try without installing
claude --plugin-dir ./travelerswatch
```

<div dir="rtl">

المتطلبات: يحتاج الحارس إلى Claude Code؛ وتحتاج إلى `bash` و`awk` (موجودان في macOS وLinux)؛ و`git` اختياري، لكنه يتيح عدّ الإيداعات ومراجعة ما بعد المشروع كاملة.

## 2. اليوم الأول: حدّد المسار

1. افتح Claude Code في المجلد الجذر لمشروعك.
2. شغّل **`/checkwatch`**. أجب بسطر واحد: ما المشروع، وأيّ جزء منه يوجّهه هذا المسار.
3. يقرأ Claude ملف README و`docs/` وتاريخ git الحديث، ثم يعرض **بطاقة أدلة** و**مسودات** لكل قسم. أنت تصحّحها؛ ويسأل هو عن الثغرات، والبنود الموضوعة في غير مكانها، وأي موضع تتعارض فيه إجاباتك مع الأدلة. توقّع نحو خمس جولات؛ في الاختبار المعياري للإصدار v1.0.0 كانت نحو 4 جولات في أفضل الحالات ونحو 11 في أسوئها.
4. أكّد المسار. يكتب Claude ملف `.watch/WATCH.md` ويضيف `.watch/.state` إلى `.gitignore`.
5. **أودِع السجل في git**:

</div>

```bash
git add .watch/WATCH.md .gitignore && git commit -m "watch: bearing set"
```

<div dir="rtl">

من الآن فصاعدًا، كُتبت المهارات بحيث لا يتغيّر شيء في المسار دون تأكيدك.

## 3. كل يوم

| متى | ماذا تفعل أنت | ماذا تفعل TTW |
|---|---|---|
| **بداية اليوم** | افتح Claude Code واعمل كالمعتاد. | يعيد الحارس قراءة `.watch/WATCH.md` مع أول طلب، فتكون التغييرات التي أُكّدت أمس سارية. |
| **أثناء العمل** | اطلب ما تحتاجه: شيفرة، مراجعات، مسودات. | يُنجَز العمل المتكرر داخل المسار. إذا انحرف طلبٌ، يقول Claude ذلك في **سطر واحد** ويتابع. |
| **ظهور تنبيه انحراف** | قرّر: هل كان التفافًا مؤقتًا، أم أن الطريق يتغيّر فعلًا؟ | التفاف: تابع فحسب. تغيير حقيقي: شغّل **`/fixwatch`**، وراجع الفرق وأثره، ثم أكّد أو ألغِ. |
| **«حان موعد نقطة تفتيش»** | شغّل **`/checkwatch`** حين تجد دقيقة. | يُبلغ بـ *على المسار / ينحرف / خارج المسار / المسار موضع شك* مع الأدلة، ويضيف سطرًا إلى سجل نقاط التفتيش. |
| **نهاية اليوم** | أودِع `.watch/WATCH.md` مع عملك إن تغيّر. | لا شيء آخر. لا تحتفظ TTW بأي بيانات خارج مستودعك. |
| **نهاية مرحلة أو المشروع** | قل لـ Claude: «المرحلة توشك على الانتهاء، لنُجرِ مراجعة ما بعد المشروع». | يصوغ مراجعة من سجل نقاط التفتيش وPath log وتاريخ git. وتختار أنت **المراجعة والإغلاق** أو **المراجعة فقط**. |

### ما الذي تعرفه TTW، ومتى

تتابع TTW تغييرات مشروعك اليومية عبر السجل وgit، لا بمراقبة ملفاتك. وبدقة:

| اللحظة | ما يُقرأ | ما **لا** يُقرأ |
|---|---|---|
| **كل طلب** (الحارس) | المسار وStatus في `.watch/WATCH.md`؛ وعدد الإيداعات والجلسات منذ آخر نقطة تفتيش. | شيفرتك أو الفروق أو أي ملفات أخرى. |
| **نقطة التفتيش** (`/checkwatch`) | المحادثة، و`git log` منذ آخر نقطة تفتيش، والملفات المعدّلة، والوثائق المدرجة تحت *Evidence scanned*؛ والمشكلات وطلبات السحب المفتوحة عبر أداة سطر الأوامر الخاصة بمنصة الاستضافة (مثل `gh`) إن كانت مثبّتة. | لا تتضمن قائمة قراءة المهارة أي شيء خارج مجلد المشروع. |
| **مراجعة ما بعد المشروع** | السجل كاملًا (سجل نقاط التفتيش + Path log) وتاريخ git لملف `.watch/WATCH.md`. | أي شيء خارج مجلد المشروع. |

## 4. الأوامر في لمحة

| الأمر | استخدمه من أجل |
|---|---|
| `/checkwatch` | تحديد المسار (أول مرة) · إجراء نقطة تفتيش · إجراء مراجعة ما بعد المشروع |
| `/fixwatch` | تغيير المسار عن قصد · إغلاق مراجعة · إعادة فتح مشروع مغلق |
| `/configwatch` | عرض الحالة · ضبط وتيرة نقاط التفتيش: تجريبية `every 3 commits or 2 sessions` (افتراضية)، أو ثابتة `every 10 commits or 5 sessions`، أو مخصّصة، أو `off` |

## 5. ما لن تفعله TTW نيابةً عنك

كُتبت المهارات بحيث لا تؤكد تغييرًا، ولا تقبل تناقضًا، ولا تغلق المشروع نيابةً عنك، حتى لو طلبت ذلك (تُختبَر بالتقييمات ولا تفرضها الشيفرة). ستصوغ الفرق، وتفحص أثره، وتجمع الأدلة، لتتخذ كل قرار بنظرة واحدة. وهذا مقصود في التصميم: راجع قسم «ما هي، وما ليست» في [README](README.md).

## 6. الإيقاف أو الإيقاف المؤقت

- لهذه الطرفية فقط: `export TRAVELERSWATCH_DISABLE=1`
- نهائيًا: `/plugin` ← travelerswatch ← disable (تظل المهارات تعمل يدويًا).
- تذكيرات أقل بنقاط التفتيش: `/configwatch` ← ثابتة أو `off`.
