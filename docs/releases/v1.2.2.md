# The Traveler's Watch v1.2.2

**Released:** 2026-11-26 · **DOI:** [10.5281/zenodo.24548998](https://doi.org/10.5281/zenodo.24548998) (this version) · [10.5281/zenodo.24543183](https://doi.org/10.5281/zenodo.24543183) (all versions) · **Full changelog:** [v1.2.1...v1.2.2](https://github.com/Icharu/travelerswatch/compare/v1.2.1...v1.2.2)

A **documentation release**. The skills, hook, logbook format, and license are the same as in
[v1.2.0](v1.2.0.md), so nothing changes in how TTW behaves.

## The tale, in every language

The tale behind the project, a traveler with a broken watch and a watchman on the wall, is now
available in all seven languages, each with a language bar linking to the others:

[English](https://github.com/Icharu/travelerswatch/blob/v1.2.2/docs/tale.md) ·
[Português (Brasil)](https://github.com/Icharu/travelerswatch/blob/v1.2.2/i18n/pt-BR/tale.md) ·
[Español](https://github.com/Icharu/travelerswatch/blob/v1.2.2/i18n/es/tale.md) ·
[繁體中文](https://github.com/Icharu/travelerswatch/blob/v1.2.2/i18n/zh-Hant/tale.md) ·
[简体中文](https://github.com/Icharu/travelerswatch/blob/v1.2.2/i18n/zh-Hans/tale.md) ·
[日本語](https://github.com/Icharu/travelerswatch/blob/v1.2.2/i18n/ja/tale.md) ·
[العربية](https://github.com/Icharu/travelerswatch/blob/v1.2.2/i18n/ar/tale.md)

Each translated README now links to the tale in its own language. The line *"Watchman, what of the
night?"* (Isaiah 21:11) uses the traditional public-domain Bible wording where available (Chinese
Union Version, Reina-Valera, Van Dyck). Translations are machine-assisted, and native-speaker reviews are
welcome.

## Fixed

- **The version number is now the same everywhere**: plugin manifests, skill metadata,
  `CITATION.cff`, `.zenodo.json`, and the README badges and citations. v1.2.1 still reported 1.2.0,
  so its Zenodo record showed the wrong version.
- The translated READMEs no longer send readers to the English tale.

## Upgrading

```bash
claude plugin marketplace update travelerswatch
claude plugin update travelerswatch@travelerswatch
```

Nothing else to do. Existing logbooks keep working unchanged.
